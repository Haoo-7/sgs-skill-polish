## 一、技能的结构

### 1.1 分类与标签

| 标签 | 含义 | 描述开头 |
|------|------|---------|
| 锁定技 | 不存在"不发动"选项（但发动≠强制执行效果，见2.2） | "锁定技，……" |
| 觉醒技 | 满足条件后强制发动并转型 | "觉醒技，<时机>，若<条件>，……你获得〖X〗" |
| 限定技 | 整局游戏限一次 | "限定技，……" |
| 主公技 | 仅主公拥有，常与势力联动 | "主公技，……" |
| 转化技 | 把某牌当另一牌使用/打出 | 两种写法见 SKILL.md 〖武圣〗模板 |
| 隐匿技 | 有未明置状态 | "隐匿技，……" |
| 架势技/使命技/蓄爆技等 | 新机制标签 | 按 V2.2 用语章对应条目 |

状态类技能（无时机，持续成立）：如〖马术〗〖空城〗，直接写"若……则……"或数值修正。

### 1.2 效果存续（"直到……"句式）

临时性效果必须写清存续区间，标准句式：
- 直到你的下回合结束 / 直到本回合结束 / 直到你的下个回合开始
- 此回合结束前❶（配合延时效果→）
- 不写存续 = 即时效果，结算完毕即失效

### 1.3 发动流程（规则集"游戏规则"章）

有消耗技能：时机到达 → 检测条件 → 选择是否发动（消耗前的"可"）→ 执行消耗 → 执行效果。
无消耗技能：时机到达 → 检测条件 → 效果前的"可"决定是否执行。

## 二、符号系统

| 符号 | 用法 | 例 |
|------|------|----|
| 【 】 | 卡牌名 | 【杀】【无懈可击】 |
| 〖 〗 | 技能名 | 〖观星〗 |
| $〖 〗 | 同句中多个同名技能消歧 | $〖激昂〗 |
| "X" | 标记名（引号） | 置于武将牌上（称为"权"） |
| ①② | 拆分为多个独立技能 | 〖权计〗①② |
| { } | 逻辑层次分组，排版可省 | 官方偶尔使用 |
| / | 结构简化（省略共同成分） | "红/黑" |
| ▶ | 消耗 \| 效果 分隔符 | 可弃置一张牌▶你摸两张牌 |
| → | 延时类效果标记 | 见〖放权〗 |
| ❶❷❸ | 官方细分时机序号 | 见第七节 |

**"若如此做"**：效果分两段，前段操作后段追加时用。"你选择：1.……；2.……"是多分支标准句式（选择权在使用者）。

**"其"**：句中已出现的目标角色的代词，一个句子里"其"指代必须唯一；指代不清就重复写"该角色""此角色"。

## 三、时机命名

### 3.1 阶段时机（仅此五种写法）

| 写法 | 精确含义 |
|------|---------|
| X阶段开始前 | 此阶段的"阶段开始前"系统时机（如〖放权〗在此跳过阶段） |
| X阶段开始时 | 阶段刚开始的瞬间 |
| X阶段 | **=X阶段内的空闲时间点**（主动技用此写法，配"限一次"） |
| X阶段结束前 | 阶段结束前的系统时机 |
| X阶段结束时 | 阶段结束的瞬间 |

回合级别同理：回合开始前/回合开始时/回合结束前/回合结束时。注意"出牌阶段限一次"是固定搭配——次数约束挂在时机上，不是效果里。

### 3.2 事件时机

| 句式 | 视角 |
|------|------|
| 当你使用【杀】选择目标后 / 当【杀】指定目标后，若使用者为你 | 使用者 |
| 当你成为【杀】的目标时 / 当其他角色成为【杀】的目标时 | 目标 |
| 当你受到1点伤害后 / 当你造成伤害后 | 受害者/来源 |
| 判定结果确定前/后 | 判定相关 |
| 拼点结果确定后 | 拼点相关 |
| 当你死亡时 / 当你进入濒死状态时 | 自身事件 |
| 当此牌置入弃牌堆后 / 当…离开你的区域后❷ | 牌的位置事件 |

**易错**："受到伤害时"与"受到伤害后"是两个时机（时=伤害结算中扣减体力前；后=已扣减）。"造成伤害"同理。设计意图若是"以伤害为代价换效果"一般用"后"。

**注意句式**：目标视角的技能不要写"当【杀】指定目标后"（那是使用者时机），要写"当你成为【杀】的目标时"。

### 3.3 两套方言（DIY 卡面默认第二层）

| 方言 | 回合级结束时机 | 证据 |
|------|--------------|------|
| 规则集方言（凌天翼） | 细分为"回合结束前❶~❻"，**不出现**裸的"回合结束时" | 配套卷全文 0 处"回合结束时"；"回合结束前"45 处 |
| 官方游戏内文本（手杀/OL/十周年） | "每回合结束时""其他角色的结束阶段"等粗粒度写法 | 阿会喃〖蟨蛮〗、孟达〖苟得〗、罗宪〖带砺〗、笮融技能与"应机"牌均用"每回合结束时"；界朱然〖胆守〗用"其他角色的结束阶段" |

DIY 卡面面向玩家，默认用第二层；查结算顺序与语义边界回第一层。凡"官方从不/官方一律"式判断，先 grep 配套卷统计、或搜索官网武将页确认，再落笔。

## 四、操作动词精确定义（用语章核心）

| 动词 | 精确含义 | 典型误用 |
|------|---------|---------|
| 弃置 | 角色弃置**自己区域里**的牌（该角色选牌） | "你弃置B的一张牌"错——应为"B弃置一张牌"或"你获得B的一张牌并弃置之"类精确表述 |
| 令…弃置 | A令B弃置 ⇒ **B**选牌 | 与上一行对照 |
| 弃置B的一张牌 | **A**从B的区域里选牌弃置 | 与〖刚烈〗模板对照："你弃置来源的一张牌"=你选 |
| 获得 | 主动操作：把牌/技能纳为己有 | 与"得到"（结果性，如"得到此牌"）区分 |
| 交给 | 把自己拥有的牌置入目标角色的区域（牌必须先是你拥有的） | "将其一张牌交给"错——那张牌不是你的 |
| 观看 | 只查看，不亮明（如观看牌堆顶） | ≠展示 |
| 展示 | 对所有角色公开（展示后按效果处理） | ≠观看 |
| 亮出 | 牌面朝上置放或公开（判定牌"亮出"） | 三个词不可互换 |
| 重铸 | =将此牌置入弃牌堆 + 摸一张牌（固定组合） | 效果另有所指时不要用"重铸" |
| 移动 | 场上牌在区域间转移（装备/判定区） | 落幕规则、合法性另查规则集 |
| 转移 | 目标转移（〖流离〗）/ 伤害转移（〖遗计〗类），各有固定结算 | 不要自创"转移"变体 |
| 无效 | 让一个使用/技能不产生效果（可被"无效无效"类技能再交互） | ≠取消 |
| 取消 | 把一个仍会结算的使用终止（如【无懈可击】取消锦囊） | ≠无效 |
| 防止 | 伤害/效果不发生（数值层面拦截） | "防止造成的伤害"与"无效"完全不同 |
| 无视 | 忽略某规则/距离/防具（如无视防具） | ≠无效 |

**min{} 缩水**：能弃置的牌数不足X时自动缩水，官方写法"弃置min{能弃置的牌数，X}张"或用"至多"；DIY 简写"弃置X张"须在边界备注注明缩水。

**其他硬规定**：
- 双消耗不存在——一个技能只有一个消耗位
- 用到装备牌的距离/攻击范围/技能时，**不能**操作该装备牌（规则集用语章）
- 跳过一个阶段后，不能再跳过该阶段（〖放权〗类技能的边界）
- 每回合/每阶段限次以"限一次/限两次"标注在时机后
- **自指再发动合法**："你发动〖本技能〗"是效果文本的合法句式（官方先例：司马徽"你可以发动〖星舞〗……"），再发动=重走技能全文（含重新选择目标）。审查此类句式问"重算了什么、何时终止"，不要当坏味道重构成显式链条

## 五、数值与量词（含公式）

| 量 | 公式 | 备注 |
|----|------|------|
| 手牌上限 | Af = max{Ao + Δ, 0} | 状态技写"你的手牌上限+X（X为……）" |
| 额定摸牌数 | 初值2，Af = max{2 + Δ, 0} | 额定为0时不能执行"令额定摸牌数±/改为"类消耗 |
| 距离 | Lf = max{Lo + Δ, 1}；**A至B的距离 ≠ B至A的距离** | 〖马术〗只改"你至其他角色"，不反向 |
| 攻击范围 | 无武器=1；Af = max{Ao + Δ, 1} | "攻击范围内"用于选目标约束 |
| 伤害值 | -Y：若X≤Y，改为防止 | 造成X点伤害-1的完整结算 |
| 等量 | =紧邻其前的最近一个**非固定**数量 | "弃置至少一张牌▶摸等量的牌"（〖制衡〗） |
| 一半 | [X/2] 向下取整 | 描述写"一半（向下取整）"消歧 |
| X/变量 | **单处使用**：定义紧跟首次出现（〖权计〗式）；**多处使用**：整句末、句号之后统一覆盖（配套卷实例："1.{……摸X张牌……}；2.{……弃置X张牌。}。（X为你已损失的体力值）"） | 位置不影响结算；句末版勿粘在最后分句与句号之间（管辖会被误读为只管该分句）；变量必须在句内定义，不得引用武将牌外信息 |

体力/体力上限：回复、失去、减上限各有专词；"减1点体力上限"≠"失去1点体力"。伤害类别：普通伤害/属性伤害（火、雷）——"造成1点伤害"默认普通伤害，官方会写"普通伤害"（〖刚烈〗模板）。

## 六、易错点清单（审查时重点过）

1. "弃置"主语错位（谁选牌）——最高频错误
2. "时/后"混用导致结算点偏移
3. "获得技能"与"获得标记"未区分载体（技能挂在武将牌，标记在武将牌旁）
4. "视为使用/视为打出"与"使用/打出"混用——视为技不产生"使用牌"的历史计数时须写明
5. 效果里塞第二个消耗（应为①②拆分或"并"连接的同一消耗内操作）
6. "其"指代歧义（一句两个候选）
7. 变量 X 未定义就使用，或定义在另一个技能里
8. 距离修正写"你与其他角色的距离"（应为"你至其他角色的距离"，反之亦然）
9. 锁定技内写"可"却不解释执行层面选择（锁定技≠效果强制执行）
10. "本回合/此回合/你的下回合"存续区间写错
11. AOE（【南蛮入侵】【万箭齐发】类）多目标技能漏写结算顺序
12. 濒死/死亡相关技能漏写"结算完当前结算后"插入规则
13. 承前省略主语在"你/其"双候选句必然错位（实例："……你弃置所有牌并选择一名……的角色，须依次弃置X张牌"字面读作"你弃"，但"你"刚弃完所有牌无牌可弃）——补主语是 P0
14. 无"可"的非锁定技：强制/可选未定，主题（"拼将一死"之类）不能替代用户确认——标锁定技与加"可"强度不同
15. 把合法的紧凑句式报成错误：自指再发动（官方有先例）、承前省略主语（只需主语唯一）、命名牌生命周期依赖默认规则——审查时先确认机制模型再定级

## 七、官方细分时机❶~❾（进阶）

官方在复杂技能里用 ❶❷❸❹❺❻❼❽❾ 标记同名时机的细分点（如多个"回合结束前"）。DIY 描述**默认用粗粒度时机**；确需细分时，模仿〖放权〗的"此回合结束前❶"写法，并在武将说明处附时机表。全表见 V1.0 配套卷"游戏流程"章。

## 八、描述卫生

1. **标记定义**：首次出现必须"（称为'X'）"；消耗/效果引用标记一律带引号 X 为"X"数。
2. **新区域命名**：武将牌上（武将牌旁的牌）、处理区、礼物区等按规则集既有区域名；自创区域先定义"置于……（此区域为……）"。
3. **"你"恒等技能拥有者**；描述他人动作时用"其/该角色"，绝不写具体武将名。
4. **牌的数量词**：一张/至少一张/至多X张/X张（X为……）；"任意"仅在无上限且明确时用。
5. **不写实现细节**：不提"系统询问""按钮"，只写结算行为。
6. **一句一义**：长技能用①②或句号切分，每句只表达一个完整结算单元。

## 九、缩字手段（不损精度）

用户要求"字数更少"时的合法省略，均有形式定义或官方文本支撑：

1. "交给"默认从手牌区交（形式定义），"各一张手牌"可省"手牌"
2. 效果句按序结算即含"立即"——"其立即使用"可作"其使用"
3. 单次结算内"以此法弃置的牌数"自然累计，省"之和"（跨发动的独立事件之间才需要求和）
4. 多处使用的 X：句末一份定义覆盖全部，不逐处重复
5. 同句内指代用"其中的"替代"以此法获得的"
6. "每回合结束时"替代"一名角色的回合结束时"（官方先例：阿会喃〖蟨蛮〗等）
7. 主语"你"在锁定技唯一主体句中可省（"你"恒指技能拥有者）
8. 删自指冗余：X 定义一份即可，不再重复括注

**反面纪律**：原文更短常因省略了必要信息（定义、主语、时机）——净增减要如实报告并逐条给理由，"原版的短是靠歧义换来的"这句话要说给用户听。
